# Mobile_Sales_Dashboard 📱

## 1. Project Title
**Mobile Sales Analysis Dashboard**

## 2. Short Description
I created this dashboard in Power BI to analyze mobile sales data. The main purpose of this project is to understand sales performance, customer ratings, popular mobile models, and different payment methods.

This dashboard helps to get a clear idea about total sales, quantity sold, transactions, and sales across different cities and days.

## 3. Tech Stack
- **Power BI** – To create the dashboard and visualizations
- **Power Query** – To clean and prepare the data
- **DAX** – To calculate KPIs and sales metrics
- **Microsoft Excel / CSV** – For handling the dataset

## 4. Data Source
I used mobile sales data containing information about mobile brands, mobile models, sales amount, quantity, transaction details, customer ratings, payment methods, cities, and dates.

## 5. Features

- **Sales Overview:** Shows total sales, total quantity, number of transactions, and average price.
- **City-Wise Sales:** Displays sales across different cities in India using a map.
- **Daily Quantity Analysis:** Shows how mobile sales quantity changes day by day.
- **Customer Ratings:** Helps understand customer ratings.
- **Payment Method Analysis:** Compares Cash, Debit Card, UPI, and Credit Card transactions.
- **Brand-Wise Performance:** Compares sales, quantity, and transactions for different mobile brands.
- **Mobile Model Analysis:** Shows sales of different mobile models.
- **Day-Wise Sales:** Helps compare sales across different days of the week.
- **Monthly Filter:** Allows users to select a month and view the data accordingly.
