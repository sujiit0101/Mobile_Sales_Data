## Dashboard Preview

![Mobile Sales Dashboard](dashboard.png)

## Project Overview

This Power BI dashboard provides an interactive analysis of Motorola mobile sales performance, customer ratings, transactions, and payment methods.

## Key Performance Indicators (KPIs)

- **Total Sales:** 59M
- **Total Quantity:** 1K
- **Total Transactions:** 291
- **Average Price:** 41K

## Dashboard Insights

- **Sales by City:** Visualizes sales distribution across Indian cities.
- **Total Quantity by Day:** Tracks daily quantity trends.
- **Customer Ratings:** Displays customer rating distribution.
- **Payment Methods:** Compares Cash, Debit Card, UPI, and Credit Card transactions.
- **Brand Performance:** Compares sales, quantity, and transactions by mobile brand.
- **Mobile Model Sales:** Highlights top-performing mobile models.
- **Sales by Day Name:** Compares sales performance across weekdays.
